The important part first. The rest one click away.

Session, week and the forecast on open. History, sessions, statistics and every limit behind a single click.

  • Providers

    Claude and Codex, side by side

    One tab per provider with its session value. No provider colour in the data: bars, rings and graphs read the same for both. Codex appears once the Codex CLI is signed in with ChatGPT.

  • Forecast

    Will it last?

    Hollow dots show where the session lands at the reset. A marker shows how much of the window has passed. The forecast turns ochre, then red, when the limit comes early.

  • History

    Session and week in one graph

    Dot columns for the session, a red line for the week. From one hour to thirty days.

  • Menu bar

    A ring that fills

    Twelve dots, each one a twelfth of your limit. It shows the tab you looked at last and turns ochre, then red, as you get close.

  • Notifications

    Warned before it hurts

    At your warning and critical thresholds, on resets and when a sign-in expires. Each one carries a small ring with the value.

  • Usage report

    Where the tokens went

    Fresh tokens by day in an activity calendar, plus top projects and models, for either provider or both.

Reads, never writes. Spark reads the Claude Code Keychain entry and the Codex auth.json and writes neither. Codex tokens are never refreshed, so the CLI stays signed in. When the Claude token expires, Spark renews it with a refresh token it keeps in its own Keychain entry. Usage stats are parsed from local history files and stay on your Mac.

Running in a minute.

  1. 1

    Install with Homebrew

    brew install konradmichalik/tap/spark

    Or download the DMG from the releases page.

  2. 2

    Sign in once in the CLI

    claude auth login

    For Codex: codex login. Spark picks up whatever is signed in.

  3. 3

    Open Spark

    open -a Spark

    The ring appears in your menu bar. That is it.

To update: brew upgrade --cask konradmichalik/tap/spark. Requires macOS 14 or later. Build from source.
